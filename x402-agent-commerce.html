What is Stripe x402?

Stripe launched the x402 protocol on February 10, 2026. It uses HTTP status code 402 ("Payment Required") to let AI agents autonomously pay for API access — no human in the loop.

1

Agent Hits Your API

An AI agent calls your endpoint. Your server returns HTTP 402 with a payment requirement header specifying the price in USDC.

2

Agent Pays Instantly

The agent's x402 client signs a USDC payment on Base (Coinbase L2). Transaction confirms in ~2 seconds with sub-cent gas fees.

3

You Get Paid

Stripe verifies the on-chain payment and releases the API response. USDC settles to your Stripe balance or wallet. Done.

How it works under the hood
// Your API endpoint returns 402 with x402 payment details
HTTP/1.1 402 Payment Required
X-Payment-Protocol: x402
X-Payment-Network: base
X-Payment-Token: USDC
X-Payment-Amount: 0.001
X-Payment-Recipient: 0xYourAddress
X-Payment-Facilitator: stripe

// Agent pays via x402 client SDK, re-sends request with payment proof
Authorization: X402-Payment {base64_encoded_tx_receipt}

// Stripe middleware verifies on-chain, forwards to your handler
→ Your API returns the response. Settlement: instant.

Frequently Asked Questions

Is this actually secure? Agents are handling money autonomously.▼
Yes. The x402 protocol uses Stripe as a facilitator — they verify every on-chain transaction before your API releases any data. Agents pay with USDC on Base (Coinbase's L2), which inherits Ethereum's security. Stripe handles the cryptographic verification; your server never touches private keys. It's the same trust model as Stripe Checkout, just with a crypto payment rail.
What are the gas fees? Who pays them?▼
Base L2 gas fees are typically under $0.01 per transaction — often fractions of a cent. The agent (buyer) pays gas as part of the USDC transfer. This is built into the x402 client SDK. For your business, there are no gas costs — you receive USDC net of Stripe's standard processing fee.
How fast do payments settle?▼
Base block time is ~2 seconds. Stripe's facilitator confirms the transaction in real-time, so from the agent's perspective the entire pay-and-receive cycle takes 2–4 seconds. USDC hits your Stripe balance immediately. If you want USD in your bank account, Stripe's standard payout schedule applies (typically T+2).
Do I need to know anything about crypto or blockchain?▼
No. That's the whole point of hiring us. We configure the Base wallet, Stripe facilitator, and middleware. You interact with your Stripe Dashboard like any other payment method. The blockchain layer is abstracted away. You see "Agent payment — $0.05" in your Stripe logs, not hex addresses.
What if an agent tries to abuse my API?▼
Our Full and Enterprise tiers include rate limiting per agent wallet address, allowlist/denylist management, and monitoring dashboards. You can set spending caps, block specific agents, and get alerts on unusual patterns. Since every agent has a unique wallet, you have granular control.
Which frameworks do you support?▼
We've built middleware for Express.js, FastAPI (Python), Go net/http, and Rails. If you're on a different stack, we can adapt — the x402 protocol is just HTTP headers and a verification call to Stripe's API. We also support serverless (AWS Lambda, Vercel, Cloudflare Workers).
Why should I do this now?▼
x402 launched one week ago. Agent-to-API commerce is brand new. Businesses that enable agent payments now will capture agent traffic that competitors can't serve yet. Early data from Stripe shows agent API usage is growing 40%+ week-over-week. The window to be first-mover in your vertical is measured in weeks, not months.
What's USDC? Can I just get paid in dollars?▼
USDC is a dollar-pegged stablecoin issued by Circle (backed 1:1 by US Treasuries and cash). 1 USDC = $1.00, always. With our Full Integration tier, we set up automatic USDC → USD conversion through Stripe, so your payouts arrive in regular dollars. You never have to think about crypto.
